## **9\. Tablero Kanban y seguimiento**

El equipo utilizará un tablero Kanban en Jira o GitHub Projects para registrar las historias y visualizar su avance.

**Columnas propuestas:**

| Columna | Descripción |
| ----- | ----- |
| **Backlog** | **Historias pendientes de priorización o refinamiento.** |
| **Ready** | **Historias que cumplen la Definition of Ready.** |
| **In Progress** | **Historias en desarrollo.** |
| **In Review** | **Historias en revisión de código, integración o pruebas.** |
| **Done** | **Historias que cumplen la Definition of Done.** |

Cada tarjeta del tablero deberá contener, como mínimo, el identificador, el título, la prioridad, la persona responsable, los criterios de aceptación y los enlaces a la documentación relacionada.
